# Nova Client

Client-side Fabric mod for Minecraft 1.21.10. Press **Right Shift** to open the GUI.

Modules: Aimbot, AutoAttack, Anchor Macro, ESP, Fullbright, Overlay, Sprint, plus a Config tab (GUI color, particle color/speed/count/size).

In the GUI: left-click a module to open it, right-click to toggle it. Mode settings cycle on click.

## Get the jar
1. Push this repo to GitHub.
2. Open the **Actions** tab, click the latest **Build** run, and download `novaclient-jar` from Artifacts.
3. Unzip it and put `novaclient-1.0.0.jar` in `.minecraft/mods` with Fabric Loader and Fabric API for 1.21.10.

To get a download on the Releases page, push a tag: `git tag v1.0.0 && git push --tags`.

Use ESP and Aimbot only where they are allowed. Most multiplayer servers ban them.
